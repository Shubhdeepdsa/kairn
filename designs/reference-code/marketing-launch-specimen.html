PRIMARY VALUE PROPOSITION & TAGLINE
"A local-first Knowledge Management System for engineering documentation and Git history exploration."
ELEVATOR PITCH (WEBSITE HERO & PRODUCT HUNT)

Kairn bridges raw Markdown files and repository evolution into a unified, instrument-grade reading and exploration workspace. Built strictly local-first with zero telemetry, instant offline search indexing, and deep Git history awareness—empowering engineering teams to navigate system architecture with uncompromised clarity.

KEY PRODUCT PILLARS (FOR FEATURE SECTIONS & BULLETS)
Local-First Architecture

Runs 100% offline on your device with direct filesystem access. No cloud accounts, latency, or telemetry.

Git History Explorer

Inspect commit timelines, author signatures, and unified or side-by-side diffs tied directly to documentation changes.

Mineral Precision UI

Engineered Swiss typography, 4px modular rhythm, and restrained wayfinding accents that eliminate cognitive fatigue.
